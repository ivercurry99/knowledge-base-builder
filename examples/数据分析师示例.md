```
## 知识沉淀流程

1. 读完整理解 → 2. 判断归属 → 3. 问确认 → 4. 写成结构化笔记 → 5. 放入对应 Area → 6. 原文加 √

## 待沉淀 → Areas 升格三标准

1. 能用自己的话讲清楚
2. 在工作中或生活中用过
3. 能教给别人

## 门禁（Harness）

| 操作 | 完成标准 |
|------|----------|
| 沉淀知识 | 来源已读 → 归属已确认 → 笔记已写入 → Inbox 已标记√ |
| 移动文件 | 已移 → 全库链接已更新 → 残留为 0 |
```

## 使用 3 个月后的样子（示意）

小陈每天看到好文章 → 丢进 `00-Inbox/资源/`
周末统一处理 → 有价值的消化成卡片 → 按主题放进 `10-Areas/数据分析/2-分析思维/`
想学 AI → 放进 `10-Areas/AI工具/`
做小红书 → 放 `20-Projects/ing/`
发了文章 → 移进 `30-Output/done/`

3 个月后，`10-Areas/数据分析/` 里积累了 50 篇消化过的笔记，随时能查、能复用、能输出。
