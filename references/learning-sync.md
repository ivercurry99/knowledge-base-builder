# 同步学习沉淀

> 模式二「同步学习」时读取。把 `00-Inbox/待沉淀/` 里的原始材料「学习消化」成可复用知识卡片。

## 学习卡片格式（Compress 模式，默认）

每张知识卡片包含：

1. **一句话定义** —— 用自己的话转述，不是原文照搬
2. **关键概念** —— 3–5 个
3. **具体例子** —— 至少 1 个
4. **常见错误** —— 至少 2 个
5. **自测题** —— 3–5 个

## learn-anything-fast 的调用

按用户意图选择模式：

| 用户意图 | 调用模式 |
|---------|----------|
| 快速消化（默认） | Compress：压成一张卡片 |
| 想深度学习某主题 | Full loop：完整学习循环（map→focus→retrieve→correct→compress→teach→verify） |
| 想验证是否掌握 | Teach-back：费曼检验，让用户用自己的话复述 |

## 降级说明

宿主没有 `learn-anything-fast` 技能时，用等价学习循环，产出格式一致：

```text
map（拆解主题）→ focus（找核心 20%）→ compress（压成卡片）→ teach-back（费曼自检）
```

## 升格三标准（学习产出的验收）

卡片升格到 `10-Areas/` 前，确认同时满足：

1. 能用自己的话讲清楚（定义是转述，非原文照搬）
2. 有具体例子
3. 有自测题（能教别人 / 检验自己）

不满足就继续学，不硬升格。

## Obsidian 适配

学习卡片用 Obsidian 原生格式：

- **frontmatter**：`tags`、`created`、`type`、`status`
- **双向链接**：卡片顶部链接原文（`[[原文]]`）、关联相关笔记
- **callout**：需要强调时用 `> [!note]` / `> [!tip]` / `> [!warning]`

卡片写入 `10-Areas/{领域}/` 后，在原文顶部加：

```markdown
> 已学习：[[10-Areas/领域/卡片名]]
```
